# MAX REALMS 3.0 — Rise of the Shattered Kingdoms

Projeto web original de endless runner, pronto para GitHub Pages.

## Destaques da 3.0
- 6 reinos com transição durante a corrida
- 10 heróis desbloqueáveis
- chefe/Guardião do Portal
- sistema de 2 vidas
- cristais, XP, níveis, troféus e recorde
- 7 missões permanentes
- 5 conquistas
- 4 poderes: escudo, ímã, tempestade e runa x2
- upgrades de poderes até nível 5
- multiplicador progressivo
- obstáculos para pular e deslizar
- teclado + controles por swipe
- pausa e salvamento local
- responsivo para desktop e celular
- zero dependências externas

## Publicar no GitHub Pages
1. Extraia o ZIP.
2. Crie um repositório no GitHub.
3. Envie `index.html`, `README.md` e a pasta `assets` para a raiz.
4. Vá em Settings > Pages.
5. Em Build and deployment selecione Deploy from a branch.
6. Escolha `main` e `/ (root)` e salve.

## Observação de propriedade intelectual
Esta versão usa universo, personagens, nomes e elementos visuais originais. Não inclui
imagens, nomes, músicas ou assets de Game of Thrones/HBO nem assets de Temple Run.
